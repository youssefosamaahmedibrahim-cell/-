# 🔥 SECRET SHOP — متجر ثلاثي الأبعاد تفاعلي

صفحة ويب واحدة فيها **موديل 3D كامل لمتجر "SECRET SHOP"** مبني بالكود (Three.js)
من غير أي ملفات موديلات خارجية — كل الأشكال والخامات (خشب، حجر، قرميد، لافتة، رايات،
كريستالات، شلال) مولّدة برمجياً على Canvas.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
# أو نسخة جاهزة للنشر:
npm run build && npm run preview
```

## التحكم

| الحركة | الطريقة |
| --- | --- |
| لف المتجر | سحب بالماوس / إصبع واحد |
| تقريب وتبعيد | عجلة الماوس / إصبعين |
| تحريك الكاميرا | كليك يمين + سحب |
| زوايا جاهزة | الأزرار على اليمين (`الواجهة / جانبي / السطح / الداخل / من الأعلى`) |
| اختصارات | `1..6` للزوايا، `R` إعادة، `T` جولة، `Space` دوران، `F` ملء الشاشة، `H` وضع السينما |

أزرار الشريط السفلي:
- **جولة** — جولة سينمائية تلقائية بين كل الزوايا.
- **ادخل** — كاميرا تدخل جوّا المتجر.
- **دوران** — دوران تلقائي بطيء (بيرجع لوحده بعد ما تسيب الماوس).
- **صوت** — جو صوتي مولّد بـ WebAudio (درون + رياح + نغمات).
- **عن المتجر** — بطاقة المعلومات.

## اللي موجود جوه المشهد

- مبنى على طراز **الباجودا** بسقفين منحنيين (توليد رياضي للسطح + عوارض + حواف نيون).
- **لافتة SECRET SHOP** بتدرجات ذهبية/حمراء، إطار ذهبي، ومظلة خشبية فوقها.
- شعار ناري على القمة (نصال أوبسيديان بحواف ذهبية وجوهرة متوهجة).
- **شلال أحمر متوهج** بـ shader مخصص + بِركة تموّج + رذاذ.
- رايات قرمزية متحركة، فوانيس مضيئة، كريستالات، صناديق كنز، نباتات، مشاعل.
- **داخل المتجر**: أرفف بزجاجات مضيئة، كاونتر، كرة بلورية، تاج ذهبي، سجادة منقوشة.
- مدينة بعيدة في الضباب + شرر متطاير + أعمدة ضوء + سماء بنجوم.
- ما بعد المعالجة: Bloom + تدريج لوني سينمائي + حبيبات فيلم + فينييت.
- أداء: تخفيض جودة تلقائي على الأجهزة البطيئة، وإيقاف الرسم لما التاب مختفي.

## هيكل المشروع

```
index.html
src/
  main.js               # الرسم، الكاميرا، الجولة، الواجهة
  style.css             # واجهة عربية RTL زجاجية
  audio.js              # الجو الصوتي (WebAudio)
  lib/
    textures.js         # كل الخامات على Canvas
    materials.js        # مواد PBR
    shapes.js           # مكوّنات (سقف، راية، فانوس، صندوق، كريستال...)
  world/
    buildWorld.js       # تجميع العالم والزوايا والإضاءة
    shop.js             # المبنى واللافتة والشعار
    interior.js         # داخل المتجر
    surroundings.js     # الشلال، الساحة، المدينة، الأشجار
    atmosphere.js       # السماء، الشرر، أعمدة الضوء، بيئة الانعكاس
public/concept/         # صور المفهوم الأصلية
```

بدون أي اعتماديات على أصول خارجية — كل شيء يُبنى وقت التشغيل.
