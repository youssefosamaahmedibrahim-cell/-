# SECRET SHOP — نموذج المتجر ثلاثي الأبعاد

عارض تفاعلي لموديل المتجر مبني بـ Three.js، مع التركيز على المبنى وتفاصيله. لا توجد مدينة أو سماء أو مؤثرات خلفية في المشهد؛ الـ canvas شفاف، وتُستخدم مساحة داكنة محايدة خلفه لتسهيل رؤية النموذج.

## التشغيل

```bash
npm ci
npm run dev
# نسخة الإنتاج
npm run build
npm run preview
# اختبارات الأدوات
npm test
```

افتح العنوان الذي يطبعه Vite في المتصفح. يحتاج العرض إلى متصفح يدعم WebGL.

## التحكم

- اسحب بالماوس أو بإصبع واحد لتدوير المتجر، واستخدم العجلة أو إصبعين للتقريب والتبعيد.
- كليك يمين مع السحب لتحريك الكاميرا.
- أزرار الزوايا تعرض الواجهة، الجانب، السقف، الداخل، أو المنظر العلوي.
- يمكن إعادة الزاوية، تشغيل الدوران التلقائي، أو ملء الشاشة من شريط الأدوات.
- زر **حفظ PNG** يصدر المنظر الحالي بخلفية شفافة، مقصوصاً حول الجزء الظاهر من النموذج مع هامش صغير. اللون الداكن للصفحة وأزرار الواجهة لا يدخلان في الصورة.
- اختصارات لوحة المفاتيح: `1` إلى `5` للزوايا، `R` لإعادة الزاوية، و`Space` لتشغيل أو إيقاف الدوران.

## الموديل

- سقف متعدد الطبقات بقرميد وحواف منحنية، وواجهة خشبية بدرابزين ونوافذ وأعمدة وإطار مدخل.
- لافتة درع مجسمة، شعار، رايات وفوانيس، درجات حجرية وتفاصيل داخلية.
- خامات مولّدة محلياً وإضاءة للموديل، مع خريطة انعكاس لا تظهر كخلفية.
- تجميع الأجزاء الثابتة لتقليل طلبات الرسم، وجودة تتكيف مع الأجهزة الأبطأ.

## هيكل المشروع

```text
index.html
src/
  main.js                  # العرض والكاميرا والتحكم وتصدير PNG
  style.css                # واجهة العارض المتجاوبة
  lib/
    textures.js            # خامات Canvas المولّدة برمجياً
    materials.js           # خامات Three.js
    shapes.js              # مكونات الموديل
    mergeStatic.js         # تجميع الأجزاء الثابتة للأداء
    alphaBounds.js         # حدود القص الشفاف عند التصدير
  world/
    buildWorld.js          # المشهد الشفاف والإضاءة والزوايا
    shop.js                # المبنى وتفاصيل الواجهة
    interior.js            # تفاصيل داخل المتجر
    dims.js                # الأبعاد المشتركة
public/
  concept/                 # الصور المرجعية الأصلية
  fonts/                   # الخط المحلي المستخدم في اللافتة وترخيصه
```

الخط **Permanent Marker** من Font Diner ومرفق بترخيصه في `public/fonts/PERMANENT-MARKER-LICENSE.txt`.
